# bensz-search 1.0.5

商业后台治理与运行观测更新，部署版本以运行实例为准。

## 新增

- 服务健康、熔断和冷却可见；按服务展示成功率、延迟分位和费用估算。
- SQLite 近 7/30 个 UTC 日的用量统计、审计日志和按密钥调用次数。
- 用户角色编辑、密码重置及停用；管理员查看和撤销全体密钥。
- 密钥过期时间与 Search API / 协议及 MCP 两类权限范围。
- 登录会话列表、退出其他设备，以及无密钥服务配置导入导出。
- 原生模块前端、抽屉配置与执行时间线、主题选择和手机卡片列表。

## 修复

- 编辑和启停服务保留未提交的引擎验证证据，切换实例时撤销旧证据。
- 提供引擎同步入口、保存并测试、一次性密钥关闭确认和未保存变更保护。
- 会话过期后保留当前表单重新登录；分类错误与字段反馈，恢复焦点和滚动位置。
- 清理服务热更新和临时测试的 LiteLLM 回调，序列化配置热更新及并发数据库迁移。

## 使用说明

延迟分位是有界直方图区间上界估算，费用为配置估算而非供应商账单。
进程内健康与最近记录会在重启后清空；每日用量、密钥计数和审计记录持久化。
升级前备份 SQLite 与对应加密密钥，回退旧代码需恢复升级前数据库快照。
