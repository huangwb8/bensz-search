# bensz-search 1.0.9

## 本次更新

- 改善搜索期间后台的响应：SQLite 与用量写入使用有界线程，缩短密码校验锁，配置快照减少重复数据库读取。
- 页面使用身份隔离的资源缓存与分区加载，保留搜索草稿；密钥和用户列表每页 50 条，公共 JS/CSS 使用完整模块图指纹、长期缓存和 GZip。
- 用户工作台增加近 7/30 个 UTC 日的个人用量趋势与各引擎统计；删除密钥保留统计历史，旧全站历史无法回填个人用量。
- 管理员增加系统设置，持久化站点信息、默认语言与帮助链接；保存具有修订冲突保护。菜单调整为搜索引擎、搜索调试、管理员密钥。
- 单 worker 默认最多 16 个进行中的搜索，超额返回可重试的 429；后台读取和健康检查不占搜索名额。官方镜像仅提供 Docker Hub linux/amd64 的 1.0.9 和 latest。

## 使用说明

性能数据来自隔离 SQLite/ASGI、浏览器合成 API 和容器 mock，不代表真实供应商吞吐量。全局与个人统计按 UTC 日计算，费用为配置估算，延迟分位使用直方图区间上界。
升级前备份 SQLite、匹配加密密钥和公共资源 bundle；回退旧代码需恢复升级前快照。仍保持单 worker，版本以运行实例为准。
