# bensz-search 1.0.8

## 本次更新

- 提升后台与用户工作区的文字可读性：正文、输入控件与搜索摘要使用 16 px，导航和表格正文使用 15 px，表头与表单标签使用 14 px。
- 统一正文行高，增强关键标签及搜索摘要的文字对比度；页面标题保留 28 px，控件高度保留 44 px。
- 手机页面说明和卡片字段标签同步优化；登录页沿用相同字体变量，浅色和深色主题共用字号规则。
- 同步部署说明与版本引用；官方镜像仅提供 Docker Hub linux/amd64 的 1.0.8 和 latest。

## 既有能力

1.0.7 新增访问密钥永久删除，并优化导航层级、筛选条、搜索高级选项与弹窗操作区。1.0.5 新增服务健康与熔断观测、近 7/30 个 UTC 日用量、审计、用户治理、密钥期限与权限范围、会话管理，以及不含密钥的服务配置导入导出。

## 使用说明

删除密钥立即失效并永久移除记录，历史审计保留。费用为配置估算；延迟分位使用直方图区间上界。进程健康与最近记录重启后清空，每日用量与审计持久化。
升级前备份 SQLite 与对应加密密钥，回退旧代码需恢复升级前数据库快照。版本以运行实例为准。
