  --provenance=false --sbom=false -f docs/deploy/Dockerfile \

升级前在服务器私有 `.secrets/release-v1.0.8-20261007/` 保存 Compose、环境配置、旧镜像 ID 和一个 SQLite 一致快照，副本 `integrity_check` 为 `ok`。旧镜像保留为服务器本地 `huangwb8/bensz-search:pre-v1.0.8-20261007`，没有上传该标签。

```bash

docker compose -f docker-compose.yml up -d --no-deps --wait --wait-timeout 180 search
```

本任务只拉取并重建 `search`，没有向其他镜像执行 pull、tag、build 或容器更新。独立 SearXNG 的容器 ID、镜像与启动时间保持不变。比对 43 个其他容器时有 42 个完全一致；`bensz-router` 的容器与镜像出现独立变化，其新启动时间为北京时间 20:54:31，早于本任务完成镜像推送和开始搜索部署的 20:56:52 之后。本任务没有操作该服务，也没有将这项差异伪记为未变化。

如需回退，应先保存升级后的新数据，再停止 `search`，选择保留的旧镜像并按需要恢复对应数据库与匹配配置，之后仅启动 `search`。恢复指引见[服务器说明](../server-deployment.md)；本次没有实际执行回退，不在日常维护中使用 `down -v`。
