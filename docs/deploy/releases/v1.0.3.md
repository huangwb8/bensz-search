## 服务器上线

部署目录 `/docker/bensz-search`。服务器 Compose 与仓库模板一致，无需变更管理员偏好。上线前在私有 `.secrets/release-v1.0.3-20261005/` 备份 Compose、环境配置与一致性 SQLite 快照，快照 `integrity_check` 为 `ok`；旧镜像保留为本地 `huangwb8/bensz-search:pre-v1.0.3-20261005`，不上传该回滚标签。

只拉取并重建 `search` 服务：

```bash
BENSZ_SEARCH_IMAGE=huangwb8/bensz-search:1.0.3 docker compose -f docker-compose.yml pull search
BENSZ_SEARCH_IMAGE=huangwb8/bensz-search:1.0.3 docker compose -f docker-compose.yml up -d --no-deps --wait --wait-timeout 180 search
```

验证搜索容器 `healthy`、安装包 1.0.3、使用项目内数据 bind mount、没有宿主机端口映射且只连接 `npm_default`。Compose 与 `.env` 字节未改变；其他 43 个容器的 ID、镜像 ID 和启动时间保持一致，包括本项目 SearXNG。没有操作其他服务镜像。

需要回滚时，沿用匹配的私有配置，仅切换搜索镜像：

```bash
BENSZ_SEARCH_IMAGE=huangwb8/bensz-search:pre-v1.0.3-20261005 docker compose -f docker-compose.yml up -d --no-deps --pull never --wait search
```

本版本未修改数据库 schema，不需要恢复旧数据库；如果另有数据恢复需求，先备份上线后的新写入，再参照[服务器恢复说明](../server-deployment.md#迁移与恢复)执行。本次保留回滚资源，未执行实际回滚。
