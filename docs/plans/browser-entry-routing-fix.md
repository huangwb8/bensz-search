# 浏览器首页路由修复

## 根因与范围

2026-10-04 公网首页及容器内部 `/` 均返回 managed access key 403，`/admin` 正常。LiteLLM 1.103.2 自带 GET `/` 需要鉴权；FastAPI 0.142.2 的 include_router 保留嵌套路由，当前按顶层 path/name 过滤无法移除该路由。上游路由先匹配，遮蔽项目首页跳转。

## 实施与验证

- 添加首页与浏览器搜索入口的无凭据跳转回归测试，先验证失败。
- 将项目 browser_entry 的 GET 路由移到路由表前端，保留搜索 POST 和管理 API 鉴权。
- 运行浏览器入口、密钥权限与协议针对性测试。
- 使用当前服务器镜像构建最小修复镜像，备份并更新部署；保持 npm_default 与数据挂载。
- 验证公网首页跳转、静态资源、未登录管理 API 拒绝访问、容器健康；同步部署说明、变更记录和 BAC。

## 恢复

服务器项目内保留修复前镜像引用与 Compose 备份，恢复原部署配置后重新启动；不删除数据卷或更改凭据。
