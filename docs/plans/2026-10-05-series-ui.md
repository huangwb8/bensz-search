# 首页与后台系列视觉优化

## 目标与边界

参考本地 bensz-router 的首页、登录及后台视觉，使 bensz-search 可被识别为同系列产品。沿用原生 HTML、CSS、JavaScript 和现有首页跳转管理台的入口，只调整界面与必要的导航呈现，保持搜索、登录、权限和配置接口行为。

本项目审计基于 revision `f9ca7e4a25be55c2e54ae5c2934bdf62c444fc9c`；参考项目基于 revision `2ca4aeb8406358abeab4fd32c81f731c6c313ea2`，仅只读研究。本次不修改 LiteLLM 搜索实现。

## 参考与方向

- 首页：`server/homepage/HomePage.vue`、`homepage.css`，学习导航、中文衬线展示标题、留白及产品能力层级。
- 登录：`server/frontend/src/views/login.css`，学习浅色入口和清晰的登录面板。
- 后台：`server/frontend/src/themePalette.css`、`workspace.css`、`layouts/WorkspaceShell.vue`，学习蓝色操作、浅灰画布、浅色侧栏、细边框和导航分组。
- 将布局与色彩原则落实为本项目样式 token，不引入 Vue 或额外 UI 依赖；产品文案围绕真实搜索能力。

## 实施步骤

- 检查工作区、BAC 主账本与现有页面，保存相同合成数据和视口的修改前截图。
- 经 awesome-code 调度门禁，派发 frontend-specialist 诊断并修改首页登录入口、后台布局与公共组件。
- 主代理在 1440 × 900、1024 × 768、390 × 844 复验登录、七个后台页面、配置和管理弹窗及搜索状态，必要时定向修正。
- 运行 JavaScript 语法、相关后端兼容性测试和静态检查；更新版本、CHANGELOG、验收说明与 BAC。

## 验收标准

- 入口和后台采用统一品牌、色彩与空间规则，具有 bensz-router 的系列识别度。
- 主要控件仍为 44px，同排字段与搜索按钮对齐；表格可在自身容器横向滚动，页面无横向溢出。
- 页面主标题清晰，辅助文字、导航选中态、焦点、错误及禁用状态可辨认。
- 移动端菜单、登录、搜索和弹窗可操作；核心数据流及管理员和成员权限保持兼容。
- 浏览器使用合成响应且明确标记；不把视觉验收作为真实搜索服务或部署证据。

## 管理员与用户工作区分离

根据用户进一步要求，增加 `/app` 用户工作台入口，保留 `/admin` 管理员后台。使用同一登录会话与既有管理 API，Cookie 范围及服务端角色和密钥归属校验保持兼容。

- 管理员后台呈现全局运行概览、服务配置和用户管理，管理员可切换到个人用户工作台。
- 用户工作台呈现个人搜索、自己的访问密钥、接入和账号设置；独立概览只使用可用来源与本人密钥数据，不展示全局指标或假造个人用量。
- 成员进入 `/admin` 后转到 `/app`，登录与会话恢复按实际角色选区；各区有各自导航、标题和 URL，刷新及浏览器历史保持页面一致。
- 复验管理员／成员／管理员个人区、两入口、跨区切换、刷新后退、登录退出、空与错误状态；同步版本为新功能次版本 1.1.0。

## 侧栏简化与折叠

按用户继续明确的偏好，直接学习 bensz-router 的 `WorkspaceNavigation.vue`：管理员上方、用户下方，各自可独立展开和折叠；区内页面平铺，删除工作空间、搜索工具、账号等额外分类，以及横向工作区切换控件。

- 管理员同时看到两区的页面链接，成员仅看到用户区。
- 两个折叠按钮只控制列表可见性，提供 `aria-expanded` 和 `aria-controls`；默认两区展开，页面与区域切换保持折叠状态。
- 链接同时标记区域和页面，只突出当前区域的当前页；跨区点击与前进后退同步内容、URL 和侧栏状态。
- 复验三个视口及手机菜单、折叠按钮键盘操作、跨区与历史导航；修订版本更新为 1.1.1。
