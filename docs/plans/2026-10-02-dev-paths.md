# 开发环境与缓存归档计划

## 需求与实施

- 将根目录 `.venv`、`.pytest_cache`、`.ruff_cache` 迁入 `.bensz-api/`，保留现有环境与缓存，修正环境启动脚本的绝对路径。
- 在 `pyproject.toml` 中固定 pytest 与 Ruff 缓存路径；通过 `scripts/uv.sh` 设置 uv 环境位置、项目内依赖缓存和工作目录，避免依赖用户级配置。
- Docker 构建与运行使用 `/app/.bensz-api/.venv`；同步开发命令、目录约定、审计环境路径和变更记录。`CLAUDE.md` 继续引用 `AGENTS.md`。
- 检查迁移后的命令可用性、开发入口在不同工作目录及已有环境变量下的路径、pytest/Ruff 运行结果和根目录无上述目录；验证 BAC 并追加证据。

## 边界

uv 不支持在项目配置中设置 `UV_PROJECT_ENVIRONMENT`，开发统一经由入口运行；直接调用 uv 或显式传入工具的路径覆盖选项仍可绕过项目默认配置。现有 Git/Docker 忽略规则继续保留，防止旧路径产物意外入库或进入构建上下文。
