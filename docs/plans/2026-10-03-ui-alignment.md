# 前端表单对齐优化

## 目标与边界

根据用户提供的搜索调试台截图，统一后台表单的控件高度、标签与帮助文案间距、同行字段和按钮对齐。沿用现有绿色与浅灰视觉、原生 HTML/CSS/JavaScript，不改变搜索路由、API、权限或数据存储。

## 实施步骤

- 审计共用 `.field`、`.form-row`、`.search-bar`、`.search-options` 和按钮样式，保存同条件修改前截图。
- 由前端专项子代理统一控件尺寸与下拉框外观，修复同行字段、搜索按钮和移动端间距。
- 主代理检查登录、七个后台页面及配置、测试、用户、密钥弹窗；在 1440 × 900、1024 × 768、390 × 844 下复验尺寸、溢出、键盘焦点、错误和禁用状态。
- 运行相关静态与后台兼容性检查，同步版本、变更记录、验收说明和 BAC 贡献记录。
- 更新本机 Docker 服务，确认实际提供的静态资源与源码一致；保留部署数据卷。

## 验收标准

- 搜索筛选下拉框与数字输入同高，同一行顶边、底边对齐。
- 搜索输入与提交按钮同高，桌面底边对齐，移动端自然堆叠。
- 长标签与帮助文案不会挤歪同行控件；窄屏表单和弹窗不溢出。
- 下拉框仍可通过键盘操作，数字输入保持原生数值约束与步进，复选框不受文本控件尺寸影响。
- mock 浏览器状态检查与实际后台验证分别记录，不将样式验收视为真实外部检索验收。
