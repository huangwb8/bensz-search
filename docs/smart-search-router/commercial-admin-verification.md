## 自动化验证

全量 pytest：**270 passed，7 warnings，13.72 秒**。警告均为既有 FastAPI `ORJSONResponse` 弃用提示。新增回归位于 [test_admin_governance.py](../../tests/test_admin_governance.py)、[test_admin_observability.py](../../tests/test_admin_observability.py) 和 [test_console_releases.py](../../tests/test_console_releases.py)，既有 native、auto、协议、MCP、联邦搜索和后台测试继续通过。

```sh
sh scripts/uv.sh run --no-sync pytest -q \
  --basetemp '.bensz-api/task-20261007-商业后台/shared/pytest-delivery'
sh scripts/uv.sh run --no-sync ruff check src/bensz_search tests
sh scripts/uv.sh run --no-sync ruff format --check src/bensz_search tests
sh scripts/uv.sh lock --check
```

Ruff 检查和格式门禁通过，53 个 Python 文件格式符合要求；锁文件一致性通过。五个 JS 模块通过 `node --check`，各行不超过 300 字符。CSS 组件没有直接写入十六进制颜色，字号使用六档变量。`git diff --check` 通过。命令按顺序运行，避免项目 uv 入口的锁冲突。

后端复核发现的 Router 回调累积、批量费用漏计、并发热更新覆盖、引擎同步竞态和并发迁移问题均已修复并加入回归。110 次刷新后的回调数量恒定；正在执行的请求结束或取消后才清理旧 Router。安全复核覆盖管理读写权限、CSRF、同源、最后管理员、会话和密钥生命周期、审计脱敏以及导入原子性。没有未解决的 Critical/Important 发现。

## 浏览器验收

正式资源由本地 HTTP 服务加载，并使用实际 CSP 响应头；API 数据由脚本合成，不访问真实供应商。Chrome 在 1440×900、1024×768、390×844 三个视口执行登录、两区逐页导航、配置/测试/用户/请求/密钥抽屉、401 重登录、查询约束、结果保留、未保存保护、一次性密钥、XSS、空态/错误、主题与会话刷新。脚本同时检查管理员和成员的原型属性页名回退、跨区版本显示，以及导航取消后的 URL 恢复。

三个视口均无页面横向溢出；浏览器脚本错误和 CSP 违规为空。每个视口发生 11 次合成写请求。主代理复看桌面概览、手机配置抽屉和深色设置等截图；跨页面版本显示回归已修正。

证据保存在本次任务的 `shared/ui/report.json`、61 张 PNG 和 `shared/pytest-delivery.log`。任务目录为 `.bensz-api/task-20261007-商业后台/`，不纳入正式源码；浏览器脚本纳入 `tests/`，可用安装了 Playwright 的 Python 执行：

```sh
python3 tests/ui_smoke.py --output '.bensz-api/task-20261007-商业后台/shared/ui'
```

之前的品牌截图仅用作系列视觉参考。其合成数据与当前脚本不同，没有把这次检查表述为同数据的像素比较。键盘交互和焦点逻辑已检查，但未完成屏幕阅读器和所有页面的纯键盘人工走查，不宣称完成全面可访问性认证。
