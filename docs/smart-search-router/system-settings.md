# 系统设置

管理员侧栏新增“系统设置”，地址为 `/admin/#system`。个人区的“账号设置”继续负责改密码、登录设备和个人外观。管理员菜单中的 Search API、搜索调试台、全体访问密钥分别更名为“搜索引擎”“搜索调试”“管理员密钥”；管理员密钥仍可管理全体用户的密钥，权限范围与原接口保持兼容。

## 站点信息

可保存站点名称、副标题、默认语言、使用文档链接和联系支持链接。名称显示在登录页及工作台品牌区、浏览器标题；副标题显示在登录表单。帮助链接显示在用户区的帮助页面，留空则隐藏，API 文档入口保留。链接只允许不带用户名、密码的 HTTP(S) 地址；服务端不抓取链接内容。

默认语言应用于之后新打开的页面，默认简体中文。英文沿用项目现有词典，缺少的条目回退到中文；本次没有补齐全站英文翻译。保存语言不会重建当前页面或清空当前草稿。

设置存入现有 SQLite 的 `meta` 表，重启后保留；旧数据库未保存设置时使用内置默认值，不覆盖原有用户、引擎或密钥。每次保存递增修订号，提交旧修订返回 409，页面保留草稿并允许管理员重新加载。切换设置分组保留表单，离开页面或重新加载会检查未保存修改。

## 外观

沿用跟随系统、浅色和深色三个主题，即时生效并保存在当前浏览器，与站点保存及修订独立。可继续在个人账号设置中修改。

## 安全与服务

显示软件版本、公开注册状态、固定 12 小时登录会话期限、安全 Cookie 状态，以及 Search API、协议和 MCP 地址与权限范围。提供搜索引擎、管理员密钥和 API 文档入口。

这些状态反映现有实现；系统设置不提供修改会话或 Cookie 策略的入口。安全 Cookie 由 `BENSZ_SEARCH_COOKIE_SECURE` 管理，部署变更后重启服务。公开注册未开放，用户由管理员创建。

## 接口与验证

| 接口 | 权限与用途 |
|---|---|
| `GET /admin/api/site` | 公开站点展示信息，不含修订号、部署状态、用户或凭据 |
| `GET /admin/api/settings` | 管理员读取设置、修订号和部署状态 |
| `PUT /admin/api/settings` | 管理员提交全部站点字段及 `expected_revision`；沿用 Origin、CSRF 校验和审计 |

参考 bensz-router 的站点信息、外观、安全与服务分组和修订保护；参考仓库基于 `4146794`，本地工作树可能包含后续修改。没有移植其设备授权、支付或公开安装文档功能。

定向验证见 `tests/test_system_settings.py`；浏览器冒烟 `tests/ui_smoke.py` 使用真实静态资源与合成 API，覆盖三种视口、草稿、主题、保存和修订冲突。验证不代表真实搜索供应商调用或生产部署。
