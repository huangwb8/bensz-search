# 商业后台使用与实现说明

## 交付范围

2026-10-07，基于 `404c56994a4fba2dd7b8a6dd74d65c24a52e8d81` 与工作区已有 1.0.5 品牌区修订，落实现有[商业后台计划](../plans/2026-10-07-commercial-admin-ui.md)的阶段 0–3。实现阶段源码暂为 1.1.0，按发布要求统一交付为 1.0.5；镜像和服务器升级另见 [v1.0.5 发布验收](../deploy/releases/v1.0.5.md)。该实现阶段未调用真实搜索供应商。LiteLLM 仍为锁文件固定的 1.103.2 发行包，没有修改 upstream 源码。

## 管理与个人工作区

管理员区集中全局概览、Search API、用户、全体密钥、审计和搜索调试；账号设置、我的密钥、接入和帮助统一放在用户区。成员不能访问管理接口。版本继续位于产品名下方，沿用白灰蓝系列视觉；主题支持跟随系统、浅色和深色。

服务配置在右侧抽屉中编辑，按类型显示相关字段，固定底部保存操作；“保存并测试”保存成功后直接打开测试。SearXNG 可同步实例引擎，显示已验证列表与证据。编辑、启停时未提交的证据字段保留，显式空值可清除；改变实例地址或类型时旧证据失效，删除引擎时只保留仍配置的验证子集。

服务、密钥和用户支持筛选、排序和更多操作；手机显示卡片列表。停用最后一个服务有明确警告。一次性密钥在复制或关闭时受保护；列表只显示前缀。表单具备未保存保护，切页移动标题焦点，局部刷新恢复滚动和触发控件焦点。过期提醒和重新登录保留当前表单与结果；身份变化后重新检查角色，不能继续沿用旧权限。

调试台支持权威性、召回、精度、语义、来源多样性、延迟与费用偏好，以及域名过滤和数值预算。结果和服务测试保留在当前登录页面内存，退出后清除；不写入浏览器持久存储。执行详情使用路由、尝试、融合时间线，原始数据放在高级折叠区。查询分享链接不自动执行搜索；链接可能包含用户主动分享的查询，分享前应确认内容适合披露。cURL 使用凭据占位符。

## 观测口径

| 内容 | 范围与含义 |
|---|---|
| 本进程 | 当前进程生命周期的累计请求；趋势最多保留 30 个 UTC 日，最近事件最多 200 条、页面最多展示 20 条 |
| 近 7/30 天 | 包括今天在内的 7/30 个 UTC 日，读取同一 SQLite 文件内的每日汇总；不是滚动小时窗口 |
| 服务请求数 | 实际执行的物理尝试次数，多个服务或回退会使服务次数之和大于逻辑请求数；跳过不计入服务请求数 |
| 请求成功率 | 返回可用结果的请求比例，包含部分成功；无结果计失败 |
| 服务成功率 | 实际尝试的成功/部分成功比例；空结果、超时和其他错误不计成功 |
| p50/p95 | 固定延迟直方图区间的上界估算；不是精确样本分位，溢出桶显示上界 120000 ms |
| 费用 | 已配置的保守查询费用估算，包含失败后仍预留的费用；不是供应商账单 |
| 健康 | 当前进程最近实际调用或后台测试的观测；未知不代表可用，额度/鉴权失败进入 300 秒冷却 |
| 密钥调用次数 | 通过该密钥执行的逻辑搜索请求数；native auto/named、协议 HTTP 与 MCP 共用记录，发现能力和 dry run 不计数 |

原生 auto/named、后台调试、协议和 MCP 执行均进入共同遥测与持久化汇总，服务测试只更新健康、不混入搜索用量。健康、熔断、最近事件重启后清空；每日统计、密钥使用时间/次数和审计日志持久化。每日统计保留 365 天，按天/服务存有界计数和直方图，不保存搜索词、结果 URL 或正文。当前部署仍为单机单进程；共享 SQLite 的事务保护不等于已验证多副本健康、限速与路由一致性。

持久化失败时搜索继续使用进程指标，`metrics.counters.persistence_errors` 增加并输出不含敏感参数的错误日志。应监控数据目录可写性与磁盘空间，不把成功返回的搜索当作 SQLite 写入成功的证据。

## 权限与账号生命周期

用户编辑支持角色、启停和密码重置。最后一个启用管理员的计数和修改在 SQLite writer 事务中完成，禁止删除、停用或降级。停用和密码重置撤销该用户全部登录会话；停用同时拒绝独立应用密钥，重新启用不恢复旧会话。角色每次请求从数据库读取，改变角色即时作用于已有会话。

密钥默认兼容 `search` 与 `protocol` 两个范围，可选未来过期时间。`search` 对应原生搜索 POST 与 `/search/tools` 工具发现；`protocol` 对应 v1 能力/搜索及 MCP。过期、撤销或账号停用立即拒绝新的鉴权；已经开始的请求不强制中断。管理员必须显式指定 `scope=all` 才能查看或撤销其他用户密钥，普通成员始终按本人 ID 查询。

会话列表只返回独立随机 ID、创建/过期时间及当前标志，不返回 cookie hash 或 CSRF。退出其他设备只删除当前用户的其他会话。所有管理写接口沿用 Origin 和 CSRF 校验；管理 GET 接口使用管理员依赖。

审计仅写时间、操作者数字 ID、动作、对象类型与对象 ID，不复制用户名、密码、密钥、查询或完整配置。审计写入与治理变更在同一事务内；删除操作者不会删掉历史审计。引擎同步、配置导入和其他配置更新同样留下变更记录。

## 接口补充

接口前缀为 `/admin/api`；原有接口保持兼容。

| 接口 | 主要字段 |
|---|---|
| `GET /overview?window=process\|7d\|30d` | `metrics.summary/by_provider/trend/recent`、`health`；持久化窗口仅管理员可读 |
| `GET /providers/health` | 进程内状态、冷却秒数、最近错误与观测时间 |
| `PUT /users/{id}` | 可选 `role`、`enabled`、`password` |
| `GET /keys?scope=mine\|all` | 所有者、期限、范围、最后使用与调用次数，无完整密钥 |
| `POST /keys` | `name`、可选 Unix 秒 `expires_at`、`scopes` |
| `DELETE /keys/{id}?scope=mine\|all` | 按显式范围撤销 |
| `GET /audit` | `actor_id/object_type/since/until/limit/offset`，分页最多 200 条 |
| `GET /usage?days=7\|30` | 日汇总、服务汇总与统计口径 |
| `GET /sessions` / `POST /sessions/revoke-others` | 本人会话与退出其他设备 |
| `GET /providers/export` / `POST /providers/import` | `{version:1,providers:[...]}` |
| `GET /releases` | 当前版本、版本说明和公开 GitHub 最新稳定版本；检查结果缓存一小时，失败不阻断后台 |

导出仅允许公开配置字段，不含 API Key、凭据存在标志或引擎证据。导入先验证所有配置，不覆盖同名服务，冲突时整批回滚；需凭据的服务默认停用，随后编辑密钥并测试。引擎证据必须在目标实例重新验证。版本检查只访问固定公开 GitHub release URL，不发送任务、查询、配置或凭据；旧发布版本不会提示降级。

## 实现与升级

前端使用无构建步骤的原生 ES 模块，组件默认转义插值，外链限制 HTTP(S)，事件通过委托处理；CSP 继续禁止内联脚本和样式。后端使用现有 provider adapter、管理依赖和 SQLite；新增列/表为增量迁移，保留旧身份、凭据和默认密钥权限。迁移与首次初始化串行获取 SQLite writer 锁，WAL 切换仅对短暂锁冲突做有限重试。

服务热更新串行读取和发布新 Router，旧 Router 的物理调用结束后调用 upstream `discard()` 清理自身回调；临时测试始终在结束时释放。引擎同步在抓取后使用 writer 事务比较配置及凭据，拒绝覆盖并发修改。

升级前备份 SQLite 与匹配的 `BENSZ_SEARCH_SECRET`。旧代码使用按列数插入会话/密钥的语句，不能直接在迁移后的库上回退；回退须同时恢复升级前数据库快照。真实升级与备份证据见 [v1.0.5 发布验收](../deploy/releases/v1.0.5.md)；未执行数据库回退。

自动化与浏览器验证记录见[商业后台验收](commercial-admin-verification.md)。
